## Demo-Only Media And Imported Content

The following asset groups are not relicensed as original project-owned media:

- `assets/audio/` - audio tracks used by the rhythm demo.
- `assets/covers/` - cover images used by the song-selection UI.
- `assets/charts/` - runtime chart JSON and catalog data, including content
  imported from osu!mania-style source material.
- `assets/showcase/` - GIF/MP4 recordings of the demo for portfolio review.

These files are included for demonstration, review, and local playback of this
project only. Do not redistribute them as standalone media assets or use them in
another project unless you have the required rights from the original
